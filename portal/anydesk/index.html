Requisitos

  • Windows 10 ou Windows 11.
  • Permissão de administrador para instalar.
  • Acesso à internet para conexão AnyDesk.
  • Uso apenas por pessoas autorizadas.

Depois de instalar

Abra pelo atalho Anydesk GADX na Área de Trabalho. A janela mostrará os sites cadastrados, a lista de máquinas e o botão Conectar.

Para que serve?

O launcher centraliza os acessos remotos de suporte, reduzindo erro de digitação de IDs e padronizando o ambiente.

1

Organização por site

Máquinas separadas por abas, como Casa68, Guatupê e Purunã, facilitando encontrar rapidamente a estação correta.

2

Acesso rápido

Botão de conexão por máquina, com busca por nome, função ou ID AnyDesk.

3

Ambiente padronizado

Instala o cliente AnyDesk GADX e usa atalhos já configurados para o operador/técnico.

Como instalar

O processo é simples e deve ser feito apenas em computadores de suporte autorizados.

Baixe o ZIP

Clique em Baixar pacote ZIP e salve o arquivo no computador.

Extraia com a senha interna

Use a senha informada pelos canais internos autorizados para extrair o instalador.

Execute o instalador

Abra o instalador como administrador e confirme a instalação em C:\Suporte\AnyDesk-GADX\.

Abra o launcher

Use o atalho Anydesk GADX, selecione o site e clique em Conectar na máquina desejada.

Dúvidas frequentes

Algumas respostas rápidas para uso e suporte.

O launcher substitui o AnyDesk?

Não. Ele é uma interface auxiliar para abrir conexões usando o cliente AnyDesk GADX padronizado.

Posso instalar em qualquer computador?

Não. A instalação deve ser feita somente em equipamentos autorizados para suporte interno.

O que fazer se o AnyDesk não abrir?

Verifique se o instalador foi concluído, se o Windows não bloqueou o arquivo e se existe conexão com a internet.

Quem devo chamar em caso de problema?

Entre em contato com o suporte interno: suporte@araucariadx.com.
